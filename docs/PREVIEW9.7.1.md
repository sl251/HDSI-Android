# HDSI Android 0.1.0-preview.9.7.1

本版修复图片生成、下载、发送和动态插图，并改进面向普通用户的诊断。Android versionCode 为 **37**，包名与历史签名保持不变。

## 免费生图

- 保留 ImageFree 免费渠道。站点拒绝自动请求或要求验证时，可在原任务点击「打开免费生图」，在应用内的独立网页完成验证和生成，再点击网页 Download / 下载。图片读取后自动接回原聊天、动态、头像或测试任务。
- 画面描述会填入空白输入框，也可以点击「复制画面描述」后粘贴。网页验证与生成由用户操作；不绕过站点验证，不自动切换付费服务。
- 也可点击「使用已下载图片」从相册接回结果。取消网页保留原任务；原任务已经保存图片时重复确认不会重复生成或投递。
- 「空间 → 语音识别与生图」新增「保存并测试生图」。测试会调用当前渠道，兼容 API 可能计费；测试图片仅显示在设置页。

ImageFree 是第三方免费网页服务，队列、网络、验证和可用性由站点控制。本版提供正常网页接续途径，**不承诺免费服务始终可用或全自动免验证**。参考 [ImageFree 官方排障说明](https://imagefree.net/blog/imagefree-limits-files-and-troubleshooting)。

## 图片与动态

- 修复图片 CDN 跳转被直接拒绝的问题，逐跳检查地址，不携带生图 API 密钥。
- 兼容缺少图片 MIME 的二进制图片、纯文本 Markdown 图片和 Gemini 完成的 SSE 响应；为 Base64 响应预留编码开销。
- 生成图片统一允许 16 MiB，Android 读取与头像使用限制同步调整；贴纸原有 10 MiB 限制保留。
- 生成结果先缓存。下载、保存或发送失败可继续处理已有结果，不重新生图；服务端提交结果未知时仍避免重复提交。
- 同一回合输出文字动态及相同内容的配图时，把图片补到原动态，避免重复发帖。
- 动态选图去重，部分上传失败保留已成功的图片。聊天和动态里图片读取失败时可点按重载。

## 诊断与界面

- 聊天输入区旁显示图片任务状态和诊断入口；动态也有图片任务入口，不必回到长聊天顶部寻找报错。
- 消息诊断增加「图片」筛选，包含聊天、动态、头像和测试任务；按失败阶段给出处理建议，可直接检查生图设置或重试获取、保存、发送。
- 「失败」只筛选尚未恢复的消息或图片故障。可选的向量检索降级单独显示，每个连接只显示最近状态，恢复后不再持续报故障。
- 检索诊断不再把后台与不同消息的事件合并。向量模型连续失败后退避 1–5 分钟，避免批量记忆处理反复请求与提示。
- 去掉连接 QQ 后底部「空间」导航的红色未读角标；信箱内会话未读信息继续保留。
