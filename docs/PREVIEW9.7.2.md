# HDSI Android 0.1.0-preview.9.7.2

本版重构移动端 UI、色调体系、弹簧动效与聊天栏语音输入交互，并极简化各页面文案与布局。Android versionCode 为 **38**，包名与历史签名保持不变。

## 界面与动效重构（FlClash / Material 3 风格）

- **Material You 色彩层级体系**：引入五套高对比柔和种子色板（晴空蓝、松叶绿、蔷薇粉、暮光紫、暖茶棕）与深浅色自适应 Surface Container 层级（`--surface-rgb`、`--surface-low-rgb`、`--surface-high-rgb`），取代原先偏灰的米绿底色。
- **精细化毛玻璃与物理弹簧动效**：仅在顶部状态栏、底部悬浮胶囊导航栏、聊天输入坞与弹窗层启用适度高斯模糊与高光内描边（`--glint`），配合弹簧曲线（`cubic-bezier(0.34, 1.56, 0.64, 1)`）与按压微缩放反馈，滑动与切换更加轻盈自然。
- **Bento 卡片化空间与现代气泡**：空间页采用 Bento 双列圆角卡片矩阵，聊天页采用非对称圆角对话气泡，见闻页采用分段胶囊切换器（Segmented Pill Tabs）。

## 聊天栏内嵌 QQ 风格语音输入与极简布局

- **聊天栏内嵌「按住 说话」模式**：在故事页点击 `＋` 选择「语音」后，自动收起扩展面板并将聊天栏切换为 `[⌨ 键盘切换] + [按住 说话] + [😊 表情] + [＋ 扩展]` 布局；支持长按说话、上滑取消，录完后可在上方语音条一键发送或移除，点击左侧键盘图标即可切回文字输入。
- **界面极简化**：去除故事、见闻、角色库、动态与空间页冗余的英文装饰眉标、句号后缀、抒情副标题及底部常驻回车提示，收紧首屏留白，让内容区域更加纯粹。
- **控件对齐修复**：修复滑动开关（Switch）在未选中与选中状态下的圆点居中定位，优化中文字体回退顺序与胶囊按钮 Flex 垂直居中对齐。

## 升级说明

升级前建议先导出完整故事 ZIP，直接覆盖安装 `HDS-Android-0.1.0-preview.9.7.2-arm64.apk`，不要先卸载旧版。
