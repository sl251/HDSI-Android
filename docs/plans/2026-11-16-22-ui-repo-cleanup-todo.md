## 2026-11-17 第三轮截图追加｜真正的 Edge-to-Edge 全屏铺满（已在分支 `feat/edge-to-edge-and-copy-polish` 实现，待真机验收）

> 现象：用户 2026-11-17 两张实机截图中，**顶部系统状态栏与底部系统手势导航区域露出独立的纯色背景，和 App 内自定义壁纸、模糊玻璃背景断开**。这不是要求隐藏时间、电量或底部手势条；目标是让**背景绘制延伸至物理屏幕四边**，而顶部交互控件、底部导航胶囊、输入栏仍避开系统区域。此项随后通过 PR #29 合入 `main`，并发布于 Preview 9.7.5；**仍待真机最终验收**。

### 已定位的主要原因（根据 2026-11-17 修复前的源码）

- `android/app/src/main/java/io/hdsinterlude/android/MainActivity.java` 已调用 `WindowCompat.setDecorFitsSystemWindows(getWindow(), false)`；但同一文件的 `ViewCompat.setOnApplyWindowInsetsListener(container, ...)` 把 `bars.top` / `bars.bottom` / `ime.bottom` 直接转换成了 **WebView 父容器 padding**。结果 WebView 实际绘制区域缩小，上下没有被网页壁纸覆盖；`updateSystemBars()` 把父容器涂成固定 `#20241f` / `#f5f3ed`，在暗色壁纸与其他自定义主题下形成截图里的明显色带。
- `index.html` 已有 `viewport-fit=cover`；`capacitor.config.ts` 配置 `android.adjustMarginsForEdgeToEdge = 'disable'`；`apps/mobile-ui/style.css` 中 `:root.native-insets` 把 `--safe-top/--safe-bottom` 清零，`main.tsx` 会给原生运行态加这个 class。当前等于是**完全依赖原生父容器 padding 避让系统栏**，CSS 自己不会对完整 WebView 再作避让。
- `apps/mobile-ui/glass.css` 已使用 `100dvh`、固定背景 `.custom-background { position:fixed; inset:0 }` 以及底部 `nav` 的安全区变量。**单改背景色、简单给 `body` 写 `100vh` 或关闭全部 padding，都不能完整修复**；必须同时检查原生容器布局与 WebView 安全区策略。

### P0｜正确实现全屏绘制（Native + WebView 联动）

- [x] **让 WebView 的绘制区域真正覆盖状态栏和底部导航栏后方**。移除 `MainActivity` 父容器的 `bars.left/top/right/bottom` padding，显式配置透明状态栏/导航栏、API 29+ 关闭强制导航栏对比度蒙层（`setNavigationBarContrastEnforced(false)`）、开启挖孔延伸模式，并将冷启动兜底底色对齐新玻璃色板（`#f4f6fb` / `#0f141d`）。
- [x] **使前端只对交互内容使用安全区间距**：由 `WindowEdgePolicy` 按屏幕 `density` 换算后通过 `MainActivity`（含 `WebViewListener` 页面加载重放）注入 `--safe-top` / `--safe-right` / `--safe-bottom` / `--safe-left`；移除 `:root.native-insets` 强制置零逻辑，并为表单控件增加 `scroll-margin-top/bottom` 防止固定栏遮挡聚焦项且不干扰阅读锚点。
- [x] **主题与壁纸真正贯通上下区域**：新增 `HdsRuntimePlugin.syncSystemBars` 与前端高不透明度自定义壁纸顶栏亮度采样，使状态栏/导航栏图标明暗色跟随应用内主题与壁纸亮度实时切换；三键导航与真机表现待 APK 实测。
- [x] **键盘和系统栏独立处理**：父容器仅在 `imeVisible && ime.bottom > 0` 时独立垫高底部；`:root.ime-visible` 下自动归零 `--safe-bottom` 与 `--nav-height` 消除双重补偿，原生环境停用 `visualViewport` 启发式检测避免双轨冲突（已覆盖 `tests/story-ui.mjs` 与 `WindowEdgePolicyTest.kt`，待真机软键盘实测）。
