# HDSI Android 0.1.0-preview.9.7.3

本版集中打磨移动端界面与交互：把散落在各页的提示收敛成一个明确操作，让聊天输入栏稳定停靠在底部，并把角色/故事切换提到顶栏。核心叙事、存储与备份协议未改动。Android versionCode 为 **39**，包名与历史签名保持不变。

## 故事页：一个状态一个动作

- 移除顶栏的 HDS / INTERLUDE 品牌字样，睡眠态不再显示「未完待续」旋转装饰、「等你轻轻唤醒」标题与占据半屏的空白玻璃卡。
- 按真实状态只保留一个主操作：未选角色显示「选择角色」，缺模型显示「连接故事模型」，可唤醒显示「唤醒」，失败显示「重试唤醒」。
- 唤醒过程中按钮原位显示进度，不重复启动；只有安装、失败等需要说明的情况才展开细节。
- 重新调整唤醒动效节奏，唤醒与重试的过渡更连贯。
- 新手引导的定位改为挂在稳定的顶栏操作区，删除品牌字样后不会失效。

## 聊天：输入栏底部停靠、消息方向对齐

- 聊天页改为占满可视高度的 flex 布局，输入栏常驻在四栏导航上方的固定间距，不再停在屏幕中段，也不随最后一条消息浮动。
- 同步 `--header-height` 与 `--nav-height`，滚动区、输入栏与导航之间的间距统一。
- 修复角色表情包相对文字气泡右偏：贴纸与图片不再单独决定横向位置，角色内容统一靠左、用户内容统一靠右。
- 输入栏降低阴影与焦点紫边，去掉刺眼的白色描边；修复滑块透明动画的延迟。

## 顶栏角色切换与人格库入口

- 顶栏新增角色切换胶囊（头像 + 角色名 + 下拉箭头），展开即可切换已保存的故事，点按外部或按 Esc 关闭。
- 下拉底部提供「人格与角色库」入口，直接进入导入、创建与修改人设的页面。
- 聊天页右上角新增聊天设置快捷入口，不必先回空间再逐级查找。

## 空间子页与表单组件

- 空间总览与各设置子页统一返回头，去掉装饰箭头、重复标题和冗余提示，补充双向切页动效与草稿缓存，返回时保留此前编辑内容。
- 通知与提醒设置改用自绘的液态玻璃下拉框（`SelectField`），替代 Android 原生的回车键选项弹窗，样式与暗色/浅色主题一致。
- 「重新开始 / 恢复备份」等危险操作确认改为挂载到 `document.body` 的底部弹层，支持返回键拦截、滚动锁定、防连点与执行中禁用。
- 调整设置子页的留白与卡片层级，减少大块说明文字。

## 升级说明

升级前建议先导出完整故事 ZIP，直接覆盖安装 `HDS-Android-0.1.0-preview.9.7.3-arm64.apk`，不要先卸载旧版。本次仅涉及移动端界面层，9.7 系列的备份格式与上游引擎行为保持不变；真机上的软键盘联动与 430 px 宽屏基线仍需实测。
