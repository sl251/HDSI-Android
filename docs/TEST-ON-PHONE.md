# HDSI Android Preview 9.7 真机验收清单

当前验收版本：`0.1.0-preview.9.7`（versionCode 36，Android 8.0+ / ARM64）。此清单用于**人工真机验证**，模拟响应和 CI 通过不能替代实际 API、QQ 和 TTS 验收。

## Preview 9.7 专项（本轮真机未执行）

- [ ] 使用独立测试角色：导出生图排队中的存档并恢复，保持暂停至少 1 分钟；确认无新 API 提交/图片/动态，明确恢复后仅继续一次。
- [ ] 生图等待期间录音转写；确认文字先返回，暂停故事后媒体等待停止，未知提交不自动重复生成。
- [ ] 新旧 ZIP 往返恢复；新清单版本与 APK 一致，超限给出错误且不会覆盖已有目标文件。
- [ ] 超过 200 条聊天逐页读取，包含相同时间戳的消息；关键词/日期搜索、加载前的阅读位置、切换角色和后台回来补拉均正确。
- [ ] 首次对话准备的连接失败保留未完成状态；测试通过、唤醒、实际回复后才完成。
- [ ] 持续在线/节省电量分别锁屏 30 分钟，记录耗电、CPU 唤醒、主动消息与 QQ 延迟；省电模式保活到期后不再持续持锁，返回前台能继续。不要把模拟策略测试写成续航实测。

## 准备与升级
- 从 [Preview 9.6 Release 或最新预览页](https://github.com/sl251/HDSI-Android/releases) 下载 APK，记录手机型号、Android/厂商系统版本、ABI、可用空间和此前的 APK 版本。
- 有旧数据时先导出角色的**完整故事 ZIP**，保存到应用外部位置，再覆盖安装；**不要卸载重装**，否则应用私有数据可能被清空。
- 准备独立测试角色；真实模型请求和 MiMo 试听可能产生费用。QQ 使用自己愿意承担协议及账号风险的测试账号。
- 每项记录 PASS / FAIL / NOT RUN，并保存脱敏日志。真机未执行的项目不得勾选通过。

## 一、安装、运行与界面
- [ ] 首次安装、环境准备、首次唤醒：HDS 与 SQLite 正常启动；失败时显示具体日志和恢复入口。
- [ ] 旧版覆盖升级：角色库、人设、故事、记忆、设置和密钥存在状态保留；重启 App 再检查。
- [ ] 休眠后重启、切换两个角色：聊天与故事互不串用，不重复发送开场白。
- [ ] 在窄屏、输入法弹出、前后台切换和锁屏 10 分钟后测试：底栏及输入区未被遮挡；注意 Android 省电策略可能中断后台服务。
- [ ] 网络中断或空间不足时，安装/恢复操作给出可理解的失败提示，不宣称成功。

## 二、模型、聊天和记忆
- [ ] 在「空间 → 任务分工」配置主叙事、记忆处理、Alter 等模型，执行连接测试，检查切换和错误反馈。
- [ ] 连续多轮文字聊天，检查流式显示、回复失败/重试、历史加载和重启后内容。
- [ ] 给支持图片的模型发送图片；另测无识图能力或独立识图模型配置下的反馈。
- [ ] 在「见闻」修改事实、记忆和待办，再唤醒，核对角色隔离及状态一致性。
- [ ] 有意开启持续生活/主动联系时检查请求次数、预算及后台行为；默认关闭状态不应自动产生模型调用。

## 9.6 新增体验
- [ ] 在「聊天与输入」开启流式，观察逐步显示；断网后保留已显示内容，原消息重试不重复插入用户消息。发送失败只出现一个重试入口，重试历史消息保留另写的草稿。
- [ ] 设置连续消息合并等待、回车发送/换行，检查合并时机、Shift+Enter / Ctrl+Enter、中文输入法确认及切换故事。
- [ ] 通过聊天扩展从相册选图、调用系统相机，分别检查成功、取消、权限拒绝与后台恢复。
- [ ] 点按与按住录音、上滑取消、试听、准备语音和 STT 转文字；无 STT 时提示未转写，真实识别成功后可修改再发送。
- [ ] 动态展开/收起保留草稿，用户发帖、上传配图、点赞/取消点赞、评论/删除评论；角色获知互动后允许不回应，两个故事内容互不混用。
- [ ] 配置生图渠道与视觉档案，角色自主发起自拍或动态配图；失败、结果未知和重启不会重复提交任务，也不会阻断普通对话。
- [ ] 在独立「角色头像」上传任意图片，更换/移除不修改形象档案或参考图；聊天和动态同步更新，不设置时聊天不显示头像。切换故事、重启和 ZIP 恢复后仍正确。
- [ ] 按人设生成头像后先预览，点击使用后才替换；生成头像不成为聊天消息，也不自动发布动态。
- [ ] 浅色/深色/系统主题及五种配色下，表情包设置与其他页面一致；320px 窄屏设置不溢出，导航光条留在所选格内。
- [ ] 检查悬浮、通知栏、静默、内容预览、应用内横幅、跨午夜安静时段和系统权限被拒绝后的行为。
- [ ] 两个同名地点或切换坐标后检查天气实际解析地点，离线缓存保留原时间，不冒充最新天气。

## 9.6.3 生图配置与恢复
- [ ] 生图排队期间切换 Gemini / Imagefree 渠道，未提交任务使用最新设置，不再出现旧配置拦截。
- [ ] 对旧配置检查失败的任务点击重试；有远端任务编号或图片地址时只查询/下载，不重复生成，关闭或切换渠道后仍可恢复。
- [ ] 明确被服务拒绝后修正设置，自主生图无需等待旧失败的冷却；成功任务仍遵守冷却。未知提交及重启后未知任务不能重复生成。

## 9.6.2 生图修复
- [ ] 在「空间 → 语音识别与生图」切换自动、OpenAI Images、聊天式和 Gemini 原生格式，保存并重启，检查接口格式和参考图开关保留。
- [ ] 用实际渠道分别测试文字生图与参考图；Imagefree 排队完成后图片入库并显示，不再继续查询；站点要求验证时显示明确提示。
- [ ] 分别触发聊天配图、动态配图和头像生成，检查原消息/任务诊断关联，以及 401、额度不足、无图片、下载/保存失败的提示和失败筛选。
- [ ] 断网造成未知提交时禁止重复生成；仅投递失败时重试不发起新生图。清空诊断后在途结果不写回，导出记录不含密钥、画面描述或下载链接。

## 三、角色库、分享码及独立导入导出
- [ ] 通过分享码、SillyTavern PNG/JSON、HDS/typ0 YAML 导入角色，检查名称、开场白和世界书。
- [ ] 反复导入同一角色，检查已有编辑不被意外覆盖；不唤醒故事时角色仍可在角色库显示。
- [ ] **不唤醒故事**直接导出原格式 JSON、SillyTavern V2 JSON、HDSI 预设 JSON、YAML 四种格式。
- [ ] 通过 Android 系统文件保存位置选择器保存导出文件，取消操作后不误提示成功；测试「复制内容」和重新导入。
- [ ] 检查导出内容不含已识别连接凭据；分享前仍需检查自由文本中的私人信息。

## 四、完整 ZIP 故事存档
- [ ] 用专用测试角色产生聊天、图片和记忆后，在「空间 → 备份与维护」导出完整 ZIP，确认文件存放在应用外部。
- [ ] 重开测试角色，确认本机最近备份可恢复；从 ZIP 恢复后消息、图片、事实与暂停状态合理。
- [ ] 使用错误角色存档、取消系统选择器、模拟中断；不应悄悄覆盖其他角色的数据。
- [ ] 确认故事 ZIP 不包含 API Key 或 QQ 登录凭证；这些需要独立保存/重新登录。

## 五、表情包与实验性语音
- [ ] 多选图片或整文件夹导入 PNG/GIF/WebP/JPEG，检查去重、包名、导入数量、动图展示与格式失败提示。
- [ ] 改名、删除单张贴纸和整包，重新唤醒后检查可选清单；已发送表情不应随包删除而消失。
- [ ] 表情库为空时正常纯文字聊天；触发表情时避免同一回复重复发送文字、图片和语音。
- [ ] 在音色工作台配置 MiMo 密钥，尝试描述设计、录音及 WAV/MP3 参考音频导入，试听、保存、绑定、改名和删除音色。
- [ ] 打开角色语音，在触发时检查播放气泡、可展开文字稿以及成功回复不重复附加文字。
- [ ] 分别测试内置茉莉、描述音色与参考 WAV 克隆：确认试听、角色真实回复都能合成；若失败，从「空间 → 消息诊断」导出脱敏原因码，区分服务商拒绝、语音冷却与桥接超时。
- [ ] 主聊天界面不再出现逐条「诊断」按钮，长按消息不唤出诊断弹窗；只保留「空间 → 消息诊断」入口。
- [ ] 关闭语音、断网、TTS 失败或等待超时，普通文字聊天继续可用；升级保留旧语音配置但不再有本机每日预算或 token 预扣，实际 MiMo API 需要真机验证。

## 六、本地 QQ 接入（实验性）
- [ ] 在「信箱」准备 QQ 组件、扫码并登录，用实际收发检验连接，而不只看在线指示。
- [ ] 自动回复保持默认关闭时，验证无未经授权的模型回复；添加好友/群白名单后再逐项打开。
- [ ] QQ 私聊发文字并收到正确回复，确认历史、重复发送防护、重连后的投递情况。
- [ ] QQ 群分别测试普通消息、**@ 账号消息**、引用回复和群规则；只在符合白名单与 @ 门禁时尝试回复，记录未回复时的相关设置及脱敏日志。
- [ ] 测试群表情包格式和可选语音、登录掉线/重连、切后台、停止核心后的行为；实验性能力的失败与账号风控风险应单独记录。
