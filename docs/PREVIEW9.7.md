# HDSI Android 0.1.0-preview.9.7

本版集中改进恢复安全、历史聊天与首次使用体验。Android versionCode 为 **36**，HDS 引擎仍为 **1.0.1-rc57**，包名与签名沿用历史预览版。

## 恢复与媒体任务

- 恢复后的故事保持暂停，排队生图、已生成图片投递和动态操作都必须等到明确恢复后才继续。手动暂停也会停止媒体调度，并中断在途网络等待。
- 语音转写与生图各有一个执行通道。长时间生图期间仍可转写语音；同类任务继续限制并发，提交结果未知时仍禁止自动重复提交。
- ZIP 导出与导入使用相同限制：单文件 512 MiB、解压总计 1 GiB（含清单）、最多 10,000 个条目、清单 2 MiB、角色元数据 6 MiB。超限会在打开目标文件前失败，避免导出一个当前版本无法恢复的存档。
- 新 ZIP 清单记录实际应用和引擎版本，格式升级为 2、数据结构版本为 1。9.7 可读取旧版格式 1 存档；**9.7 导出的 ZIP 不能由旧 APK 恢复**。格式 2 当前要求引擎版本一致，跨引擎迁移需要单独实现。

## 聊天记录与首次使用

- 首屏读取最近 50 条，支持“加载更早消息”，不再受 200 条显示上限限制。时间相同的消息使用消息 ID 作第二排序键，避免漏页或重复。
- 增加关键词与日期查找；关键词按文字匹配，日期定位到当天及之前。加载旧消息保留阅读位置，后台回来时补齐遗漏消息；很长时间未打开时先读取最多 500 条连续近期消息，更早内容继续分页读取。
- 新手导览后增加可操作的首次对话准备：选择角色、填写连接、真实测试连接、唤醒、发送第一句话。测试失败不会标记成功，收到实际角色回复才完成准备流程。连接测试可能产生少量 API 费用。

## 后台与电量

- “空间 → 持续生活”新增后台运行方式。默认“持续在线”保留原来的保活行为；可选“节省电量”，在退到后台或最后一次主动操作后最多保活 10 分钟，再允许 CPU 休眠。
- 省电模式下，锁屏后的回复、主动联系与 QQ 消息可能延迟；回到前台后继续。需要及时后台消息时可选择持续在线。
- 聊天刷新接入原生消息事件，15 秒轮询作为补偿；状态检查改为 3 秒。隐藏界面暂停常驻及设置页的周期读取，回到前台立即核对状态与聊天。

## 工程检查与验证范围

- 两条 CI 工作流覆盖 `upstream/**`、构建脚本、依赖锁和 TypeScript 配置变更。
- `npm run typecheck` 同时检查界面与运行时。项目运行时代码要求零类型错误；上游现有 **133 条**类型诊断记录在显式基线中，新增加或发生变化的诊断会使 CI 失败。这不是宣称上游已全面通过类型检查。维护方式见 [RUNTIME-TYPECHECK.md](RUNTIME-TYPECHECK.md)。
- 新增真实 Koishi/SQLite 宿主回归、暂停/并发测试、ZIP 格式兼容和边界测试、省电策略单元测试，以及 320px 界面的分页、搜索、后台轮询与首次对话回归。
- 发布流水线要求前端与宿主检查、Android 编译/lint/原生单元测试、签名验证、实际 ARM64 运行环境与 QQ 无账号冒烟检查通过。
- 本轮未执行 Android 真机覆盖安装、实际锁屏续航测量或 QQ 账号登录验收；不提供未经测量的省电比例。人工步骤见 [TEST-ON-PHONE.md](TEST-ON-PHONE.md)。
