# HDSI Android 0.1.0-preview.9.7.5

本版重点完成 **Android 原生与 WebView 联动的 Edge-to-Edge 全屏铺满绘制**、**动态状态栏/导航栏明暗图标适配**、**空间休眠卡片精修** 与 **全局设置冗余常驻文案清理**。核心叙事、存储与备份协议保持兼容，Android `versionCode` 为 **41**，包名与签名证书保持不变。

## Edge-to-Edge 全屏铺满与动态系统栏适配

- **全屏壁纸与毛玻璃贯通**：移除原生 WebView 父容器对系统状态栏、底部手势栏与屏幕挖孔的收缩内边距，显式配置透明状态栏/导航栏并关闭 Android 10+ 强制导航栏对比度遮罩（Scrim），开启挖孔延伸模式，使自定义照片壁纸、渐变背景与顶部毛玻璃延伸至物理屏幕四边；冷启动窗口兜底底色同步对齐新版液态玻璃明暗色板（`#f4f6fb` / `#0f141d`）。
- **四向安全区精准避让**：原生窗口按设备屏幕像素密度换算后向 WebView 注入 `--safe-top` / `--safe-right` / `--safe-bottom` / `--safe-left` 变量（并在页面加载生命周期自动重放），确保顶栏控件、底部四栏导航胶囊、聊天输入框与弹层稳妥避开状态栏、手势条和横竖屏挖孔区。
- **状态栏图标明暗实时同步**：新增原生 `syncSystemBars` 桥接与前端高不透明度自定义壁纸顶栏亮度采样，在应用内切换浅色/深色主题或更换浅白/深色照片壁纸时，自动切换系统状态栏时间、电量图标深浅色以保证可读性。
- **软键盘（IME）独立避让**：仅在软键盘实际可见时由原生容器垫高底部，并在前端自动归零底部安全区与导航高度，消除键盘上方的重复空白；原生环境下停用浏览器 `visualViewport` 启发式检测，避免横竖屏旋转引发基线漂移。

## 空间休眠名片精修与全局设置减噪

- **空间首页精修**：在已选角色且模型就绪时移除「本地核心已休眠，经历与记忆完好留存」与「本地核心运行中，随时响应对话」等重复说明，不留空行占位；消除卡片右上角与顶栏重复的休眠/在线状态标签（仅保留失败异常警示），收紧卡片留白并提升深色背景下次级说明对比度。
- **静默自动保存与子页清理**：普通自动保存不再常驻占用页面高度，消除连续切换设置开关时的表单上下跳动，仅在保存失败时持续展示错误原因与「重试保存」入口，待重启横幅收敛为「有新配置待重启」；同步精简外观、消息通知、检索、持续生活、故事设定、表情包与音色页面的重复口号，完整保留破坏性操作确认、计费与权限说明。
- **测试与诊断增强**：`HdsRuntime.recordInsets` 扩充全屏安全区尺寸诊断记录；`scripts/test-ui.mjs` 统一聚合全部 14 项移动端 UI 回归测试套件。

## 升级说明

升级前建议先导出完整故事 ZIP 备份，直接覆盖安装 `HDS-Android-0.1.0-preview.9.7.5-arm64.apk`，请勿先卸载旧版。本次仅涉及 Android 窗口适配与移动端界面层，9.7 系列的备份格式与上游引擎行为保持不变。
