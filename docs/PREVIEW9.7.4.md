# HDSI Android 0.1.0-preview.9.7.4

本版围绕「故事主界面、表情抽屉、见闻与动态、空间结构、诊断与新手引导及全局轻触手感」进行系统性液态玻璃质感与交互升级。核心叙事、存储与备份协议保持兼容，Android `versionCode` 为 **40**，包名与签名证书保持不变。

## 故事主界面与顶栏交互

- 聊天输入区去除冗余的 `'唤醒后发送…'` 占位符（统一为 `'发消息…'`），并移除未唤醒状态下底部的 `'请先唤醒核心再添加图片'` 提示。
- 未唤醒主界面重构为半透明液态玻璃 **「角色静候名片舱」**（展示角色头像、人设摘要、模型与就绪状态徽标以及主唤醒按钮），消除唤醒前画面空旷感。
- 顶栏右侧状态胶囊支持 **「已休眠 ⇄ 在线」** 双向轻触切换，点击「在线」可直接让核心回到休眠状态。

## 液态玻璃表情抽屉与交互反馈

- 表情抽屉去掉顶部 `'表情包'` 标题与关闭按钮，升级为半透明液态玻璃弹出容器并配合轻量弹性过渡动效。
- 聊天栏表情包按钮在激活打开或按压时呈现明显的变暗加深反馈；点击抽屉与表情开关之外任意区域可自动收起表情抽屉。

## 见闻、动态与未唤醒提示弹窗

- **见闻页面**：去掉顶部 `'见闻'` 标题以及 `'之前的经历留在这里，下一句话由你开始。'` 引导语，突出时间线、记忆与心绪分段视图。
- **动态页面**：下移「分享此刻」发布卡片以留出舒适的顶部呼吸空间，移除 `'唤醒故事后可发布与互动。'` 与 `'第一条动态，从你的今天开始。'`；核心未唤醒时点击「分享此刻」会弹出居中的半透明液态玻璃提示弹窗（支持 `立即唤醒`、`稍后`、Esc 与物理返回键关闭）。

## 空间页重构（四分组收敛）与顶部状态玻璃修复

- 去掉空间页顶部标题及冗余文字，重构 `section.space-wake` 状态卡片为**单层纯净液态玻璃**，消除双层模糊叠加造成的局部色块断层。
- 合并冗余入口并收敛为 4 个结构化分组：**角色与叙事**、**对话与日常**、**模型与多模态**、**外观与系统**。
- 各合并设置子页顶部统一配备半透明液态玻璃分段胶囊（如「角色与故事」下的角色与叙事 / 人格与角色库，「模型与任务分工」下的模型连接 / 任务分工 / 高级与节奏），保持子页整洁不杂乱；「外部连接与信箱」入口保留在「对话与日常」分组内。

## 消息诊断、新手引导与全局轻触反馈

- **消息诊断**：弹窗容器、sticky 粘性吸顶标题栏、过滤胶囊与排查建议面板全面升级为液态玻璃样式（保留红色 `#e5484d` 失败态提示与 320px 窄屏无溢出适配）。
- **新手引导**：移除信箱相关引导步骤，重构为 6 步基本功能引导，并为引导弹窗与目标高亮框补齐半透明液态玻璃质感。
- **全局统一轻触按压反馈**：引入 `--press-scale`、`--press-scale-sm`、`--press-scale-card`、`--press-bg`、`--press-ease` 与 `--press-primary-filter` 交互变量，为底部导航栏、设置入口卡片、角色切换、分段胶囊、各类弹窗以及主/次按钮带来统一的按压缩放与底色反馈。

## 升级说明

升级前建议先导出完整故事 ZIP 备份，直接覆盖安装 `HDS-Android-0.1.0-preview.9.7.4-arm64.apk`，请勿先卸载旧版。本次仅涉及移动端界面层，9.7 系列的备份格式与上游引擎行为保持不变。
